Selected Projects

ChainPlanner: Long-Horizon Planning for Frozen World Action Models[Code] [Demos]
2026
  • Plan-Once, Track-Steps Architecture (G5): Built a 2B VLM planner (RynnBrain1.1-2B + LoRA) on top of a frozen 10-task Phoenix-MWA WAM. One planning query converts free-form or goal-only instructions into a numbered skill plan; asynchronous step queries (every 2–3 s) track completion using a one-line language memory without re-reading the original instruction, supporting arbitrary order and repeated skills.
  • Synthetic Chaining from Single-Task Data Only: Synthesized 155k skill-chain samples from 5,273 single-task episodes (~42 h, 775 held-out episodes) with hard negatives; converged in ~1.5 h on 8×A100. Co-located on one GPU with Phoenix-MWA (~5 GB VRAM, 0.3–0.6 s/query).
  • Separated Offline & Real-Robot Evaluation: In closed-loop offline replay (G5, explicit skill names, 300 held-out chains of 2–10 skills), completed 260 / 300 chains with 0 / 1,500 wrong next-skill switches (and 62 / 73 vs. 19 / 73 for an untuned frontier model). On the real dual-arm robot, completed 22 of 26 multi-skill episodes without intervention across two planner versions (G2 + G5, up to 5 consecutive skills).
